# Simple Watermark App

Proyecto creado como herramienta personal que añade marcas de agua personalizadas a tus imágenes de forma rápida y sencilla.

## Características

- **Firma o Mosaico diagonal** - Elige cómo mostrar tu marca de agua
- **Múltiples imágenes** - Procesa varias imágenes a la vez
- **15 fuentes** en 3 categorías (cursiva, profesional, neutral)
- **3 niveles de opacidad** - Sutil, moderado o pronunciado
- **9 posiciones** para la firma
- **Vista previa en tiempo real**
- **Descarga individual o ZIP** para múltiples imágenes
- **100% client-side** - Tus imágenes nunca salen de tu navegador

## Uso

1. **Agrega imágenes** - Arrastra archivos o haz clic en el área de subida
2. **Personaliza** - Ajusta texto, tipo, opacidad, fuente y posición
3. **Descarga** - Una imagen o ZIP con todas

## Tecnologías

- HTML5, CSS3, JavaScript vanilla
- Glassmorphism UI con gradientes
- JSZip para descarga múltiple
- Google Fonts
